1. World Layoffs — Data Cleaning & EDA
Cleaned and analysed a global dataset of tech company layoffs to uncover trends across industries, countries, and time periods.
	
Tools	MySQL 8.0, MySQL Workbench
Skills	Data cleaning, Window functions, CTEs, Time-series analysis
Dataset	Layoffs.fyi — community-tracked tech layoffs worldwide

What's inside:
•	Full data cleaning pipeline — deduplication, standardization, NULL handling, type conversion
•	Exploratory analysis — company/industry/country breakdowns, rolling monthly totals, year-wise rankings with DENSE_RANK()
